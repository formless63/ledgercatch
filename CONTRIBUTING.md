# Contributing

Use the standalone installation and verification commands in README. Discuss significant behavior changes in an issue, keep changes focused and include affected test evidence. Report security-sensitive findings privately through the repository's Security → Report a vulnerability feature when the public destination is configured.

Synthetic fixtures only: never attach real order pages, account/session cookies, invoices, API keys, database dumps or private addresses. Reproduce with minimal fictional examples. Preserve owner/share checks, exact money semantics, worker-safe imports and immutable migration history. Parser output changes require a version bump and matching fixtures. Run both app and extension checks when their shared capture contract changes.

Contributions are provided under this repository's MIT license. Preserve applicable third-party notices.
